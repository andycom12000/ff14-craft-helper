# prototype-192 — 新 IA 的首屏與頁面節奏視覺定稿

Throwaway。解 [#192](https://github.com/andycom12000/ff14-craft-helper/issues/192)。

## 跑法

直接用瀏覽器開 `ia-visual-proto.html`（≥1440px）。方向鍵或底部膠囊切換變體。

| `?variant=` | 內容 |
|---|---|
| `D`（預設） | **定稿** — Ⅰ層圖左文右 / Ⅱ層文左圖右 |
| `A` | 尺寸差 — Ⅰ滿幅大圖 / Ⅱ雙欄小圖 |
| `B` | 飽和度差 — 同尺寸，Ⅱ層收走色彩預算 |
| `C` | 密度差 — Ⅰ鬆散區塊 / Ⅱ連續報表帶 |

## 三個變體的實測

視窗 1600 × 1000，`document.body.scrollHeight`：

| 變體 | 全頁高 | Ⅰ層 | Ⅱ層 | Ⅱ 佔內文 |
|---|---|---|---|---|
| A 尺寸差 | 5617px | 3166 | 997 | 24% |
| B 飽和度差 | 6261px | 2846 | 1969 | 41% |
| C 密度差 | 5514px | 3118 | 933 | 23% |
| **D 定稿** | **5509px** | **3101** | **946** | **23%** |

## 原型回答了什麼

1. **Ⅱ層權重差用密度**，不用尺寸也不用飽和度。B 的去飽和讀起來次要，但捲動預算與Ⅰ層相當（1969 vs 933），且 `filter: saturate()` 會連 ⚑ 警示徽章一起洗掉。
2. **Ⅰ層收成圖文兩欄**。原本 8 張滿幅圖佔內文 51–56%，1600px 寬的梯形漏斗失真。收成 1029px 圖 + 300px 側欄後，側欄拿到一個功能性槽位：`ANCHORED BY` + 該待辦當期讀數。
3. **兩層鏡像**（Ⅰ 圖左文右、Ⅱ 文左圖右）讓「入場券」在兩層都看得見 —— #185 那道防復胖落層規則因此在頁面上永遠有實體。
4. **⚑ 兩種態**：整張不可信＝斜紋蓋滿；一半可信＝斜紋只蓋被指名的欄位 + 虛線邊界。
5. **暗期 placeholder** 在Ⅰ層是一個 290px 的空框，但側欄的「門檻待資料 · 2026-08-28」給了它理由。
